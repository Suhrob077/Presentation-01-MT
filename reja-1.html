Graf nima?
Malumotlar tuzilmasi va algoritmlar
Ta'rif
Graf — bu tugunlar (vertices) va ularni bog'lab turuvchi qirralar (edges) dan tashkil topgan matematik ob'ekt. Graf turli ob'ektlar o'rtasidagi munosabatlarni ifodalash uchun ishlatiladi.
G = ( V , E )
Komponentlar
V — tugunlar to'plami (vertices)
E — qirralar to'plami (edges)
Har bir qirra ikki tugunni bog'laydi: e = (u, v)
Muhim tushuncha
Graflar nisbiy munosabatlarni ifodalaydi — massivlar va bog'langan ro'yxatlar esa ketma-ket ma'lumotlarni. Graf — eng moslashuvchan ma'lumotlar tuzilmasi hisoblanadi.
Graf tarkibiy elementlari
Tugun, qirra, daraja va yo'naltirish tushunchalari
Tugun (Vertex / Node)
Grafning asosiy birligi. Ma'lumotni yoki ob'ektni ifodalaydi. V to'plamining har bir elementi — bitta tugun. Masalan, shaharlar grafigida har bir shahar — tugun.
Qirra (Edge)
Ikki tugun o'rtasidagi bog'lanish. E to'plamining har bir elementi — bitta qirra. Yo'naltirilmagan grafda e = {u, v}, yo'naltirilganda e = (u, v).
Daraja (Degree)
Tugunnga tutash qirralar soni. deg(v) bilan belgilanadi. Yo'naltirilgan grafda: in-degree (kirish) va out-degree (chiqish) farqlanadi. Barcha darajalar yig'indisi = 2|E|.
Grafda Qidiruv Strategiyalari


NAVBAT (QUEUE)
ENIGA QIDIRISH (BFS)

Mohiyati: Bu usul grafni qatlam-qatlam bo'ylab o'rganadi. Markazdan boshlab barcha qo'shnilarni bir vaqtda qamrab oladi.

  • FIFO: Birinchi kelgan birinchi ko'riladi.
  • Optimallik: Eng qisqa yo'lni kafolatlaydi.
  • Xotira: Keng graflarda xotirani ko'p sarflaydi.
STEK (STACK)
BO'YIGA QIDIRISH (DFS)

Mohiyati: Algoritm bitta yo'nalishni tanlaydi va u oxirigacha yetmaguncha to'xtamaydi. Keyin orqaga qaytadi.

  • LIFO: Oxirgi kelgan birinchi chiqadi.
  • Rekursiya: O'z-o'zini chaqirish orqali ishlaydi.
  • Sikl: Grafda aylana borligini aniqlashda zo'r.

BFS Qachon kerak?

Eng yaqin do'stlar, eng qisqa marshrut va bir xil og'irlikdagi yo'llarni qidirishda foydalaniladi.

DFS Qachon kerak?

Murakkab labirintlar, o'yinlardagi ehtimollar daraxti va graf tugunlarini to'liq saralashda foydalaniladi.

Graflarni qidirish asoslari
Navbat (Queue), Stek (Stack) va Dek (Deque) tushunchalari

Graflarda qidiruv algoritmlari (BFS, DFS) shunchaki tugunlarni aylanish emas, balki ma'lumotlarni qaysi tartibda qayta ishlashni boshqarishdir. Navbat, stek va dek bu jarayonda "xotira" vazifasini bajaradi va algoritmdagi "strategiya"ni belgilaydi.

Navbat (Queue)
BFS — Kenglik bo'yicha qidiruv
FIFO (First In, First Out) tamoyili. Birinchi kirgan birinchi chiqadi. Grafda eng qisqa yo'lni topish (BFS) uchun ishlatiladi.
Stek (Stack)
DFS — Chuqurlik bo'yicha qidiruv
LIFO (Last In, First Out) tamoyili. Oxirgi kirgan birinchi chiqadi. Rekursiya yoki DFS algoritmlarida grafning tubiga tushish uchun qo'llaniladi.
Dek (Deque)
Double-Ended Queue
Elementlarni **ikki tomondan** ham qo'shish va olish mumkin. Dijkstra (0-1 BFS) kabi maxsus algoritmlarda optimallashtirish uchun ishlatiladi.
Grafni ifodalash: Qo'shnilik matritsasi
Adjacency Matrix — 2D massiv yordamida
Ta'rif

A[i][j] = 1 , agar (i,j) ∈ E

BFS — Kenglik bo'yicha qidirish
Breadth-First Search — navbat (Queue) asosida
Ishlash prinsipi
Boshlang'ich tugundan boshlab, birinchi navbatdagi qo'shnilarni ziyorat qiladi, keyin ikkinchi navbatdagi, va hokazo. Navbat (Queue) ma'lumotlar tuzilmasi ishlatiladi. Darajalar bo'yicha tarqaladi — to'lqin kabi.
function BFS(G, start): Queue Q ← new Queue() bool[] visited ← false Q.enqueue(start) visited[start] ← true while Q is not empty: u ← Q.dequeue() // u ni qayta ishla for each v in G.adj(u): if not visited[v]: visited[v] ← true Q.enqueue(v)
Vaqt: O(V+E)
Xotira: O(V)
Qo'llanilishi
Eng qisqa yo'l topish (vaznsiz grafda), komponentlarni topish, ikki tugun orasidagi masofa, grafni bo'yaklash (Bipartite check), web crawler.

DFS — Chuqurlik bo'yicha qidirish
Depth-First Search — stek (Stack) yoki rekursiya asosida
Ishlash prinsipi
Boshlang'ich tugundan boshlab, ilgari borilmagan qo'shniga chuqur kirib boradi. Yo'l tugasa — orqaga qaytadi (backtrack). Stek (Stack) yoki rekursiya ishlatiladi. Bir yo'lni oxiriga yetib, keyin boshqa yo'lga o'tadi.
function DFS(G, u, visited): visited[u] ← true // u ni qayta ishla for each v in G.adj(u): if not visited[v]: DFS(G, v, visited)
Vaqt: O(V+E)
Xotira: O(V)
Qo'llanilishi
Tsikl borligini aniqlash, topologik saralash, kuchli bog'langan komponentlar (Tarjan), labirint yechish, susaytirilgan yo'l topish.

Dijkstra algoritmi
Eng qisqa yo'l — vaznli grafda manbadan barcha tugunlarga
Ta'rif
Edsger Dijkstra tomonidan 1956-yilda yaratilgan. Vaznli grafda berilman tugundan boshqa barcha tugunlargacha bo'lgan eng qisqa yo'llarni topadi. Barcha vaznlar manfiy bo'lmasligi shart.
function Dijkstra(G, src): dist[] ← ∞, dist[src] ← 0 Priority Queue PQ ← {(0, src)} while PQ is not empty: (d, u) ← PQ.extractMin() if d > dist[u]: continue for each (v, w) in G.adj(u): if dist[u]+w < dist[v]: dist[v] ← dist[u]+w PQ.insert((dist[v], v)) return dist[]
Binary Heap: O((V+E) log V)
Xotira: O(V)
Muhim cheklov
Manfiy vaznli qirralar bo'lsa to'g'ri ishlamaydi. Bunday hollarda Bellman-Ford algoritmi ishlatiladi: O(V×E) murakkablikka ega.

Graf qo'llanilish sohalari
Graflar real hayotda va kompyuter fanida qayerlarda ishlatiladi?
Yo'nalish va navigatsiya
Google Maps, Yandex Maps — shaharlar va yo'llar graf sifatida ifodalanadi. Dijkstra va A* algoritmlari eng qisqa yo'lni topadi.
Ijtimoiy tarmoqlar
Facebook, Instagram — foydalanuvchilar tugun, do'stlik qirra. Do'stlaringiz do'stlari topish, guruhlar aniqlash graf algoritmlari bilan.
Internet va Web
Web sahifalar — tugunlar, giperhavolalar — qirralar. Google PageRank algoritmi web-grafda sahifalarni reytinglaydi.
Kompyuter arxitekturasi
Zanjirlar grafi — topologik saralash. Mikrosxemalarda kontaktlarni joylashtirish (VLSI), paralel hisoblash — vazifalar grafi.
Biologiya va kimyo
Oqsillar o'zaro ta'sir grafi, metabolik yo'llar, genetik panjaralar. Graph mining bilan kasalliklarni aniqlash.
O'yinlar va AI
O'yin xaritasi — graf. NPC harakatlari BFS/DFS bilan. Minimax algoritmi — o'yin daraxti grafi. Pathfinding — A* algoritm.
Transport tarmoqlari
Aviakompaniyalar — shaharlar tugun, reyslar qirra (vazn = narx/vaqt). Minimum spanning tree — eng arzon yo'l tarmog'i.
Cyberxavfsizlik
Tarmoq intrusion detection — graf tahlili. IP manzillar tugun, ulanishlar qirra. Anomaliya va hujumlarni aniqlash.
Loyiha boshqaruvi
Vazifalar grafi (DAG) — topologik saralash bilan vazifalarni tartiblash. Critical Path Method (CPM) — eng muhim yo'lni topish.
Graf — umumiy ma'lumotlar tuzilmasi. Murakkab munosabatlarni ifodalashning eng kuchli vositasi.
