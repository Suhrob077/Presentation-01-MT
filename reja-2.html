Grafning asosiy elementlari

Har bir graf ikki asosiy komponentdan tuziladi

Tugun (Vertex / Node)

Grafning asosiy birligi. Ma'lumot yoki obyektni ifodalaydi. Odatda V harfi bilan belgilanadi.

V = {v1, v2, v3, ..., vn}

Qirra (Edge / Link)

Ikkita tugunni bog'laydigan chiziq. Odatda E harfi bilan belgilanadi.

E = {e1, e2, e3, ..., em}

Daraja (Degree)

Bir tugunga bog'langan qirralar soni. deg(v) formula bilan ifodalanadi.

deg(A) = 3 (A tuguniga 3 ta qirra)

Og'irlik (Weight)

Qirraga biriktirilgan sonli qiymat. Masalan, masofa, narx, vaqt kabi.

w(u, v) = 7 (u va v orasida 7)

Yo'naltirilmagan graf

Qirralar ikki tomonlama aloqani ifodalaydi. Agar A va B bog'langan bo'lsa, harakat har ikki tomonga ham mumkin (masalan, do'stlik aloqalari).

Yo'naltirilgan graf (Digraf)

Qirralar ma'lum bir yo'nalishga ega (yoylar). Aloqa faqat ko'rsatilgan tomonga yo'naltirilgan bo'ladi (masalan, Instagram’dagi obunachilar yoki pul o'tkazmalari).

* Quyidagi misolda yo'naltirilmagan G(V, E) grafi tasvirlangan.

Yo`naltrilmagan Graf

Yo`naltrilmagan grafda barcha qirralar teng ahamiyatga ega. Har bir qirra faqat "bog'liq" yoki "bog'liq emas" ma'nosini bildiradi.

Qirralarda qo'shimcha raqamli qiymat bo'lmaydi. Masalan, ijtimoiy tarmoqda "do'st" yoki "do'st emas" — bu Yo`naltrilmagan graf.

  • Barcha qirralar bir xil ahamiyatga ega
  • BFS va DFS algoritmlari uchun qulay
  • Adjacency matrix faqat 0 va 1 dan iborat
Yo`naltrilmagan graf

Yo`naltrilganGraf

Yo`naltrilgan grafda har bir qirra sonli qiymat (og'irlik) ga ega. Bu qiymat masofa, narx, vaqt, xarajat kabi tushunchalarni ifodalaydi.

Masalan, shaharlar orasidagi yo'llar grafi — har bir yo'lning uzunligi Yo`nalgan bo'lib xizmat qiladi. Dijkstra va Bellman-Ford kabi algoritmlar shu graf turi uchun ishlatiladi.

  • Har bir qirra sonli qiymatga ega: w(u,v)
  • Eng qisqa yo'l algoritmlari uchun asos
  • Adjacency matrix real sonlardan iborat

Yo`naltrilmagan graf kodi

Quyida C++ tilida std::map va vector yordamida yo'naltirilmagan grafni ifodalash keltirilgan.

Bu usulda har bir tugun (string yoki int) o'z qo'shnilari ro'yxatiga bog'lanadi. Xotira murakkabligi: O(V + E).

  • STL Vector yordamida dinamik xotira
  • Yo'naltirilmagan (u ↔ v) aloqa
  • Qidiruv tezligi: O(deg(v))
graph.cpp
// Og'irlanmagan graf - C++ Adjacency List #include <iostream> #include <vector> #include <map> class Graph { public: std::map<std::string, std::vector<std::string>> adj; void addEdge(std::string u, std::string v) { adj[u].push_back(v); adj[v].push_back(u); // Yo'naltirilmagan } void display() { for (auto const& [node, neighbors] : adj) { std::cout << node << " -> "; for (std::string n : neighbors) std::cout << n << " "; std::cout << std::endl; } } }; int main() { Graph g; g.addEdge("A", "B"); g.addEdge("A", "C"); g.addEdge("B", "D"); g.display(); return 0; }

Yo`naltrilgan graf kodi

Yo`naltrilgan grafda har bir qo'shni tugun bilan birga og'irlik (weight) ham saqlanadi. C++ da bu odatda pair<int, int> ko'rinishida bo'ladi.

Ushbu struktura Dijkstra algoritmi yordamida eng qisqa yo'lni hisoblash uchun asos bo'lib xizmat qiladi.

  • Struktura: vector<pair<Node, Weight>>
  • Priority Queue orqali tartiblangan qidiruv
  • Dijkstra vaqt murakkabligi: O(E log V)
weighted_graph.cpp
// Yo`naltrilgan graf - C++ Adjacency List #include <iostream> #include <vector> #include <map> class WeightedGraph { public: // Map<Tugun, Vector<Pair<Qo'shni, yo`naltrilganlik >>> std::map<std::string, std::vector<std::pair<std::string, int>>> adj; void addEdge(std::string u, std::string v, int w) { adj[u].push_back({v, w}); adj[v].push_back({u, w}); // Yo'naltirilmagan } void display() { for (auto const& [u, neighbors] : adj) { std::cout << u << " connections:\n"; for (auto const& [v, w] : neighbors) std::cout << " -> " << v << " (vazn: " << w << ")\n"; } } }; int main() { WeightedGraph g; g.addEdge("A", "B", 4); g.addEdge("B", "C", 2); g.display(); return 0; }
