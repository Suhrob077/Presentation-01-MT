Dijkstra Algoritmi

Eng mashhur va samarali algoritm

Edsger W. Dijkstra, 1956

Gollandiyalik olim tomonidan yaratilgan. Bu algoritm faqat musbat og'irlikli qirralar uchun ishlaydi va bir manbadan boshqa barcha uzelgacha bo'lgan eng qisqa yo'lni topadi.

Vaqt Murakkabligi

O(V²)
Oddiy massiv
O(E log V)
Min-Heap
O(E + V log V)
Fibonacci Heap

Ishlash Printsipi

  1. Boshlang'ich uzelgacha bo'lgan masofa = 0, qolganlari = cheksiz
  2. Tashrif buyurilmagan uzel ichida eng kichik masofaga egasini tanlash
  3. Tanlangan uzelning qo'shnilari uchun masofani yangilash
  4. Barcha uzel tashrif buyurilguncha 2-3 qadamlarni takrorlash

Muhim: Dijkstra algoritmi manfiy og'irlikli qirralar bilan ishlamaydi!

Bellman-Ford Algoritmi

Manfiy qirralarni qo'llab-quvvatlaydi

Richard Bellman & Lester Ford, 1958

Dijkstra algoritmidan farqli ravishda, Bellman-Ford manfiy og'irlikli qirralar bilan ishlay oladi. Bu algoritm Dynamic Programming yondashuviga asoslangan.

Vaqt Murakkabligi

O(V·E)
Umumiy holat
O(V)
Xotira

Ishlash Printsipi

  1. Barcha uzelgacha masofa = cheksiz (manbadan tashqari)
  2. V-1 marta barcha qirralarni tekshirish va masofalarni yangilash
  3. Negativ tsikl borligini tekshirish uchun yana bir marta tekshirish
Afzalliklari
  • Manfiy qirralarni qo'llab-quvvatlaydi
  • Negativ tsiklni aniqlay oladi
Kamchiliklari
  • Dijkstra'dan sekinroq (O(V·E) vs O(E log V))

Floyd-Warshall Algoritmi

Barcha juftliklar uchun eng qisqa yo'l

Robert Floyd, 1962

Bu algoritm har bir uzel juftligi uchun eng qisqa yo'lni hisoblaydi. Dynamic Programming yondashuvi qo'llaniladi.

Vaqt Murakkabligi

O(V³)
Vaqt
O(V²)
Xotira

Kichik va o'rta o'lchamli graflar uchun samarali

Algoritm Formulasi

// dist[i][j] - i dan j gacha masofa
for k in 1..V:
  for i in 1..V:
    for j in 1..V:
      dist[i][j] = min(
        dist[i][j],
        dist[i][k] + dist[k][j]
      )
Qo'llash sohalari
  • Transitiv ochip o'tish matritsasini topish
  • Grafning diametrini aniqlash
  • Ijtimoiy tarmoqlarda "Six Degrees of Separation"

Dijkstra Algoritmi - C++ Kod Misoli

C++ Implementatsiyasi

        #include <vector>
        #include <queue>
        using namespace std;

        void dijkstra(int s, vector<pair<int, int>> adj[], int d[], int n) {
            priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> pq;
            fill(d, d + n, 1e9);
            d[s] = 0; pq.push({0, s});

            while (!pq.empty()) {
                int dist = pq.top().first, u = pq.top().second;
                pq.pop();
                if (dist > d[u]) continue;

                for (auto& edge : adj[u]) {
                    int v = edge.first, w = edge.second;
                    if (d[u] + w < d[v]) {
                        d[v] = d[u] + w;
                        pq.push({d[v], v});
                    }
                }
            }
        }

Foydalanish

        // A(0), B(1), C(2) tugunlar
        adj[0] = {{1, 4}, {2, 2}};
        dijkstra(0, adj, d, 3);

Texnik Tahlil

  • 📌 priority_queue - Min-heap (eng qisqa masofa)
  • 📌 1e9 - Cheksizlik (Infinity) qiymati
  • 📌 fill() - Massivni tezkor to'ldirish
  • 🚀 O(E log V) - Algoritm murakkabligi
